## 1. OddFi とは

OddFi は BNB Smart Chain（BSC）上に展開された分散型スポーツ予測マーケットです。ウォレット接続のみで利用でき、登録・メールアドレス・KYC は不要、資金はユーザー自身が自己管理します。

| 項目 | 内容 |
|---|---|
| 対応チェーン | BNB Smart Chain（BSC、chainId = 56） |
| プラットフォームトークン | ODD（BEP-20、総量 1 億枚、増発なし） |
| ログイン方式 | ウォレット接続、KYC 不要 |
| 決済方式 | デュアルソース照合 + マルチシグ承認、オンチェーン執行 |
| 入金対応 | 全 EVM チェーン |

### なぜ OddFi を選ぶのか

従来の予測マーケットには 3 つの構造的な課題があり、OddFi は資金モデルと収益分配を根本から再構築しています。

### 既存の予測マーケットとの比較

| 課題 | 従来の方式 | OddFi の方式 |
|---|---|---|
| スリッページが大きい | AMM プライシングで大口注文のスリッページが高い | Betting Pool が統一カウンターパーティとなり、固定オッズで受注 |
| 資金が遊休化 | 決済待ち資金が完全にロックされる | ポジションレンディング：未決済ポジションを担保に借入枠を発行し継続参加が可能 |
| 収益独占 | プラットフォームが利益を独占 | 誰でも Betting Pool に出資可能、シェア比例で Margin を分配 |
| トークンが業務と無関係 | トークンと事業が切り離されている | ODD は多様なユースケースを持ち、トークン価値が事業と深く連動 |

### 既存の中央集権型スポーツ予測プラットフォームとの比較

| 項目 | OddFi | 従来プラットフォーム |
|---|---|---|
| アカウント | ウォレット接続のみ | メール + KYC + 本人確認 |
| 資金管理 | スマートコントラクトで保管、運営者は単独で引き出し不可 | 運営が資金を保有 |
| 決済 | オンチェーンで検証可能 | 運営を信頼するしかない |
| 透明性 | オッズ算出過程を公開、Margin 構造も透明 | プライシングはブラックボックス |
| 出金 | オンチェーン確認後に即時着金 | 手動審査で 1〜5 日 |
| 収益分配 | マーケットメイカーが Margin を共有 | 収益は運営に帰属 |
