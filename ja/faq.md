# よくある質問

### アカウントと接続

| 質問 | 回答 |
|---|---|
| アカウント作成は必要？ | 不要です。EVM ウォレットを接続してメッセージに署名するだけ。メール・パスワード・KYC 不要 |
| 対応ウォレットは？ | MetaMask、OKX Wallet、Bitget Wallet、Phantom、Binance Wallet、Coinbase Wallet、および WalletConnect 互換のすべてのウォレット |
| OddFi のチェーンは？ | BNB Smart Chain（BSC、chainId = 56） |
| BNB は必要？ | 必要です。ガス代の支払い用にウォレットに少量保持してください |
| ウォレットでアカウントを切り替えたら？ | OddFi はアカウント変更を検知し、新しいアドレスでの再認証を促します |
| モバイルアプリは？ | OddFi は Web アプリで、デスクトップ・モバイルともに最適化済み。モバイルでは標準ブラウザ推奨 |

### 入金と出金

| 質問 | 回答 |
|---|---|
| 入金したのに残高が 0？ | 入金には 12 ブロック確認（約 36 秒）が必要です。5 分超過しても反映されない場合、BSC 上の ODD であること、正しいプロキシウォレットアドレスへ送金していることを確認してください |
| 他のウォレットへ出金できる？ | できます。任意の有効な EVM ウォレットアドレスへ出金可能 |
| 入金アドレスとログインウォレットが違うのはなぜ？ | OddFi は各ユーザーに専用プロキシウォレットを入金アドレスとして割り当てており、どのウォレットから入金しても正しく帰属できるためです |

### ベットと配当

| 質問 | 回答 |
|---|---|
| 確定前にオッズが変動したら？ | 0.05 を超える変動時はポップアップで再確認を求めます。ロックされるオッズは確定時のものです |
| 最低ベット額は？ | 最低 10 ODD |
| ベットに税はかかる？ | はい。ベット時に元本に加えて 1% ODD を賭け税として支払い、全額が直接紹介者へ。紹介者なしならプラットフォームへ |
| 配当に税はかかる？ | はい。配当時に 5% の配当税が控除されます：2pp ステーキング / 1pp L3 バッファ / 1pp プラットフォーム / 1pp 直接紹介者 |
| マルチで 1 試合だけ未確定で他は勝った場合？ | マルチ予測はすべての脚が決済完了して初めて結果が計算されます。いずれかが未決済の場合、注文全体は Pending のままです |

### ポジションレンディング

| 質問 | 回答 |
|---|---|
| 担保ポジションが勝ったが借入ポジションが負けた場合？ | 借入ポジションは通常通り敗北となり、借入額（最大で担保元本の 50%）を失います。担保ポジションは通常通り報酬支給 |

### ステーキングとマーケットメイク

| 質問 | 回答 |
|---|---|
| ステーキングを早期償還すると何を失う？ | 元本は 100% 返還、累計収益はすべて没収されます |
| ステーキング収益はどこから？ | 配当税 2pp + 早期償還の没収収益。ユーザーステーキング量 × 乗数の重み付けで分配 |

### 紹介とトークン

| 質問 | 回答 |
|---|---|
| 紹介関係は変更できる？ | できません。初回バインドでオンチェーンに記録され永久に変更不可 |
| 紹介報酬はいつ着金？ | リアルタイム着金ではありません。BettingPool に 10 ODD 以上蓄積後、Claim をクリックするとコントラクトがその場で ODD を USDT にスワップしてウォレットへ送ります |
| 紹介者は受取にステーキングが必要？ | 不要です。Clean Token モデルでは紹介者に閾値はありません |
| ODD の購入 / 売却に税は？ | ありません。ODD は Clean Token、コントラクト層はゼロ税。すべての税は BettingPool 内のベット / 配当でのみ徴収 |
| 100M 総量は増発・バーンされる？ | 増発はしません；バーン機構はワールドカップ終了後に始動し、具体的なルールは別途公表されます |
