# 手数料とセキュリティ

### プラットフォーム全体の手数料一覧

| 操作 | 手数料 | 支払者 |
|---|---|---|
| 入金（直接送金） | ガス代 | ユーザー |
| ベット | **賭け税 1%（元本に加えて追加 ODD、全額が直接紹介者へ／無しならプラットフォームへ）** | 自動控除 |
| 早期決済 | なし | — |
| 配当（当選） | **配当税 5%**（2pp ステーキング / 1pp L3 バッファ / 1pp プラットフォーム / 1pp 直接紹介者） | 配当から控除 |
| ODD の購入 / 売却 | **ゼロ税**（コントラクト層 Clean Token、売買税なし、利益税なし、クールダウンなし、1 取引上限なし） | — |
| ガス代（オンチェーン操作全般） | オンチェーンガス | ユーザー |
| 紹介者 Claim（ODD → USDT） | PancakeSwap 0.25% LP 手数料 + ガス | 紹介者 |
| 入金 / 出金（スワップ経路） | DEX 標準料率 + ガス | ユーザー |

### セキュリティ対策

| 対策 | 説明 |
|---|---|
| 自己管理 | ユーザー資金はすべてユーザーウォレットで自己管理、運営者が単独で引き出すことはできない |
| マルチシグ決済 | 試合決済には Gnosis Safe マルチシグウォレットの承認が必要 |
| ReentrancyGuard | StakingPool / BettingPool のすべての資金操作にリエントランシ保護 |
| Pausable | 3 つのコアコントラクトすべてで緊急停止に対応 |
| Claim スリッページ保護 | ODD → USDT のオンザフライスワップでデフォルト 2%、ユーザー設定可（上限 5%） |
| 最低 Claim 閾値 | 10 ODD、ガス代が小額収益を飲むのを防止 |
| L3 + L4 バッファウォーターフォール | 極端な配当は LP 資金 → プラットフォーム金庫 → L3 バッファ → L4 バッファプールの 4 層で吸収、シングルポイントの破綻を防止 |
| 第三者監査 | メインネットデプロイ前にセキュリティ監査必須（CertiK / SlowMist / PeckShield） |
| LP ロック | DEX 流動性プールの LP Token を永久ロック |
| 価格操作対策 | TWAP / オラクルクロスバリデーションでフラッシュローン攻撃を防止 |
| 残高チェック | すべての操作でフロントエンド + コントラクトの二重残高検証 |

> ODD は Clean Token であり、コントラクト層には一切の送金制限がありません。価格安定はリリーススケジュールの分散、戦略準備金による能動的価格防衛、アプリケーション層の税収循環という 3 つの事業層メカニズムで支えられています。

### リスク開示

- **スマートコントラクトリスク**：監査済みでも未発見の脆弱性が残る可能性があります。許容範囲を超える資金は投入しないでください。
- **市場リスク**：ODD 価格は市場の影響を受けます。LP およびステーキング収益が ODD 建ての場合は価格変動リスクを伴います。
- **流動性リスク**：LP 資金はロックアップ期間中は損失なしの早期償還ができません。
- **試合リスク**：極端なケース（試合中止、結果に争議）では手動決済フローが発動し、決済時間が遅延する可能性があります。
