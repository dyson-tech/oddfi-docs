# クイックスタート

### ステップ 1：ウォレットを接続

OddFi は WalletConnect 互換の主要 EVM ウォレットすべてに対応しています：MetaMask、OKX Wallet、Bitget Wallet、Phantom、Binance Wallet、Coinbase Wallet など。

**手順：**
1. 画面右上の「ウォレット接続」をクリック
2. ウォレットを選択
3. 接続リクエストを承認
4. 認証メッセージに署名
5. ログイン完了

> 初回署名で自動的に登録され、再訪問時はアドレスで識別されます。オンチェーン取引には BSC（chainId = 56）が必要で、自動切替の案内が表示されます。
>
> モバイル：ウォレットアプリがインストール済みであれば直接開いて承認、未インストールの場合はダウンロードページに遷移します。

### ステップ 2：ODD を入手する

ODD は OddFi プラットフォーム唯一の決済・計算トークンです。賭ける前に ODD を保有する必要があります。

入手方法：

| 方法 | 説明 |
|---|---|
| PancakeSwap で購入 | PancakeSwap の ODD/USDT ペアで購入 |
| クロスチェーンスワップ | Relay ブリッジ経由で他の EVM チェーン上の資産を ODD に交換 |
| 同チェーン内スワップ | PancakeSwap で BSC 上の他トークン（BNB、USDT など）を ODD にスワップ |

> ODD は Clean Token のため、購入・売却・送金すべて **税金ゼロ** です。紹介者報酬は賭け税 1% + 配当税 1pp から発生します（詳細は[紹介報酬](#8-紹介報酬)参照）。

### ステップ 3：アカウントへ入金

「ウォレット」→「入金」へ進み、自分のスマートアカウントウォレットアドレスをコピーし、ODD をそのアドレスに送付します。12 ブロック確認後（約 36 秒）に残高へ自動反映されます。

詳細は[入金と出金](#4-入金と出金)を参照してください。

### ステップ 4：予測を開始

残高反映後、試合一覧から試合を選び、マーケットと方向を選択し、金額を入力して確定すれば賭け完了です。
