# オッズの仕組み

### オッズの算出方法

第三者の専門オッズデータソースから参照倍率を取得し、元の Margin を取り除いて真の確率を復元、そこにプラットフォーム Margin 10% を加えてオープニングオッズを生成します。

```
オッズ = 1 /（真の確率 × Overround 係数）
```

典型的な Overround：110%。

### オッズの読み方

| オッズ | 暗黙確率 | 意味 |
|---|---|---|
| 1.5 | 66.70% | 大本命 — 低リターン |
| 2.0 | 50.00% | 五分五分 — 投入額の 2 倍 |
| 3.0 | 33.30% | 対抗馬 — 投入額の 3 倍 |
| 5.0 | 20.00% | 大穴 — 投入額の 5 倍 |

### 動的調整

ベッティングごとに、各方向の累計金額の偏りを自動検出して動的調整します：

- **重い方向**：オッズを引き下げ（プラットフォームのリスクを抑制）
- **軽い方向**：オッズを引き上げ（逆張り注文を呼び込みエクスポージャーを均衡化）

オッズはキックオフ 1 時間前にロックされ、それ以降は変動しません。0.05 を超える変動はリアルタイムでフロントエンドにプッシュされます。

### オッズ変動時の確認

金額入力から確定までの間にオッズが 0.05 以上変動した場合、最新オッズを表示するポップアップが現れ、再確認が必要となります。ロックされるオッズはユーザー確定時のものです。
