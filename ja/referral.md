# 紹介報酬

ウォレット接続後、ユニークな紹介リンクが自動的に発行されます。紹介関係はオンチェーンに永続的にバインドされ、一度バインドされると変更不可です。

### 報酬ソース

| 報酬の種類 | ルール |
|---|---|
| 賭け税分配 | 紹介したユーザーがベットするたびに、その元本の **1% ODD** を獲得 |
| 配当税分配 | 紹介したユーザーが当選配当を受け取るたびに、配当の **1% ODD** を獲得（5pp の配当税のうち 1pp） |
| チームランクボーナス | 下記 S1–S5 ラダー参照 |

> 報酬の受取にステーキング閾値はありません。紹介者がいないユーザーの場合、本来紹介者へ流れる賭け税 1% + 配当税 1pp はプラットフォーム金庫へ入ります。

### Claim メカニズム（重要）

紹介報酬はリアルタイムで反映されません。BettingPool コントラクト内に蓄積され、ユーザー自身が能動的に Claim します：

```
紹介ユーザーがベット / 当選 → BettingPool が ODD を Claim 残高に蓄積
  ↓
受取可能な ODD 残高を確認
  ↓
Claim をクリック → コントラクトが PancakeSwap で ODD → USDT を即時スワップ
  ↓
USDT が直接ウォレットへ着金
```

| 項目 | 説明 |
|---|---|
| 最低 Claim 閾値 | 10 ODD（少額の Claim がガス代に飲まれるのを防止） |
| スワップ経路 | PancakeSwap V2 Router（ODD → USDT） |
| スリッページ保護 | デフォルト 2%、カスタマイズ可能（上限 5%） |
| ガス | 紹介者が支払う |
| 失敗時の挙動 | スワップ失敗時は Claim 全体がリバート、ODD 残高は保持される |

> 設計意図：USDT 決済により紹介者が ODD 価格変動に晒されることを回避し、1 回の Claim にまとめることで多数の小額送金よりガス代を節約します。

### チームランクボーナス

| ランク | チーム累計ベット | チームボーナス |
|---|---|---|
| — | < $10,000 | 基本配分のみ（賭け税 1% + 配当税 1pp）、ボーナスなし |
| S1 | ≥ $10,000 | +0.04 |
| S2 | ≥ $50,000 | +0.08 |
| S3 | ≥ $100,000 | +0.12 |
| S4 | ≥ $500,000 | +0.16 |
| S5 | ≥ $1,000,000 | +0.20 |

> 階層差モデル：上位ランクは差分のみを獲得し、下位ランクのフルシェアを受け取りません。ボーナスはエコシステムインセンティブプールから支払われ、メイン Claim 経路とは別系統です。
>
> チームのベットは試合決済後にチーム累計出来高にカウントされ、報酬計算が行われます。

### 初回入金特典

| 初回入金額 | 紹介された人 | 紹介者 |
|---|---|---|
| ≥ $50 | 10 ODD | 5 ODD |
| ≥ $200 | 50 ODD | 25 ODD |
| ≥ $500 | 150 ODD | 75 ODD |
| ≥ $1,000 | 350 ODD | 175 ODD |

報酬は 30 日間ロックされ、その後受取可能になります。
