# ODD トークノミクス

### 基本情報

| 項目 | 内容 |
|---|---|
| トークン名 | OddFi Token |
| シンボル | ODD |
| チェーン | BSC（BNB Smart Chain） |
| 規格 | BEP-20（ERC-20 互換）— **Clean Token** |
| 総発行量 | 100,000,000 枚（1 億）、一回限りの鋳造、増発なし |

### トークンの用途

| 用途 | 説明 |
|---|---|
| 予測 | すべての予測は ODD 建てで決済 |
| ステーキング | 配当税分配を共有、VIP の 1 日あたりベット上限を解放 |
| マーケットメイク | Betting Pool に流動性を注入、Margin を共有 |
| ガバナンス | ODD 保有者がプラットフォーム提案に投票 |
| 報酬 | 初回入金特典、紹介報酬、エアドロップ |

### 税制（アプリケーション層の二点税制）

> すべての税は **BettingPool コントラクト** 内で徴収され、ODD トークンコントラクト自体には税ロジックがありません。ユーザーの保有 / 送金 / マーケットメイク / クロスチェーンは全工程ゼロ摩擦です。

#### 賭け税：1%

ユーザーがベットするたびに、元本に加えて 1% ODD を追加で支払います：

| 行先 | 比率 | 説明 |
|---|---|---|
| 直接紹介者（Claim 口座） | 100% | 直接紹介者の口座に蓄積、紹介者が能動的に Claim |
| 直接紹介者なし | — | 100% プラットフォーム金庫へ |

**例：** 1,000 ODD ベット → ウォレットから実際に 1,010 ODD 控除（1,000 元本 + 10 税）。

#### 配当税：5%（当選配当のみ）

| 行先 | 比率（pp） | 説明 |
|---|---|---|
| ステーキングプール分配 | 2pp | アクティブ全ステーカーへ分配（rewardPerShare モデル） |
| L3 税バッファ | 1pp | BettingPool 内部準備金へ、極端配当をバックストップ |
| プラットフォーム金庫 | 1pp | マルチシグアドレスへ移動 |
| 直接紹介者（Claim 口座） | 1pp | 直接紹介者の口座に蓄積、紹介者が能動的に Claim |
| **合計** | **5pp** | — |

**例：** 当選配当 10,000 ODD → 実着金 9,500 ODD（200 ステーキング / 100 L3 / 100 プラットフォーム / 100 紹介者）。

### 成長フライホイール

```
ユーザーのベット増加
  ↓
BettingPool が 賭け税 1% + 配当税 5% を徴収
  ↓
  ├─ 賭け税 1% ──→ 直接紹介者の Claim（ODD → USDT）→ 拡散インセンティブ
  └─ 配当税 5%：
      ├─ 2pp → ステーキングプール分配 ──→ APY 向上 ──→ ロック ODD 増加
      ├─ 1pp → L3 税バッファ ──→ BettingPool のソルベンシー強化
      ├─ 1pp → プラットフォーム金庫 ──→ 運営 / 買戻し / エコシステム
      └─ 1pp → 直接紹介者の Claim ──→ 拡散インセンティブ
  ↓
ステーキングロック + VIP のベット需要 → 自然な買い圧 → 価格上昇
  ↓
出来高拡大 → 税収絶対額拡大 → ステーキング APY が再向上（循環）
```

### 総量固定の説明

- **ゼロインフレ：** 総量 100M で固定、コントラクトに mint インターフェースなし、TGE 後は永久に増発しない
- **バーン機構：** ワールドカップ終了後に始動（具体的なルールとペースは別途公表）
- **流通量管理：** ステーキングロック + プライベート線形リリースで有効流通量をコントロール
