## 1. OddFi란 무엇인가

OddFi는 BNB Smart Chain(BSC) 위에 배포된 탈중앙화 스포츠 예측 마켓입니다. 지갑만 연결하면 바로 이용할 수 있으며, 회원가입·이메일·KYC가 모두 필요하지 않고 자금은 사용자가 직접 보관합니다.

| 항목 | 내용 |
|---|---|
| 지원 체인 | BNB Smart Chain (BSC, chainId = 56) |
| 플랫폼 토큰 | ODD (BEP-20, 총 발행량 1억 개 고정, 추가 발행 없음) |
| 로그인 방식 | 지갑 연결, KYC 불필요 |
| 정산 방식 | 이중 소스 검증 + 멀티시그 승인, 온체인 실행 |
| 입금 지원 | 모든 EVM 체인 |

### 왜 OddFi인가

기존 예측 마켓에는 세 가지 구조적 문제가 있습니다. OddFi는 자금 모델과 수익 분배를 처음부터 다시 설계했습니다.

### 기존 예측 마켓과의 비교

| 문제점 | 기존 방식 | OddFi 방식 |
|---|---|---|
| 큰 슬리피지 | AMM 프라이싱 — 대규모 베팅 시 슬리피지가 큼 | Betting Pool이 통합 상대방 — 고정 페이아웃 배당률로 수락 |
| 자금 유휴화 | 미정산 베팅 자금이 전액 락업됨 | 포지션 렌딩 — 미정산 포지션을 담보로 차입하여 계속 베팅 가능 |
| 수익 독점 | 플랫폼이 모든 이익을 가져감 | 누구나 Betting Pool에 출자 가능, 플랫폼 마진을 지분 비례로 분배 |
| 토큰의 분리 | 토큰이 비즈니스와 분리되어 있음 | ODD의 다양한 활용처가 토큰 가치를 플랫폼 활동과 직접 연결 |

### OddFi vs. 기존 중앙화 예측 플랫폼

| 항목 | OddFi | 기존 플랫폼 |
|---|---|---|
| 계정 | 지갑 연결만으로 사용 | 이메일 + KYC + 본인 인증 |
| 자금 보관 | 스마트 컨트랙트 보관 — 플랫폼이 단독 출금 불가 | 플랫폼이 자금을 보유 |
| 정산 | 온체인 검증 가능 | 운영자 신뢰에 의존 |
| 투명성 | 페이아웃 배당률 산출 공개, 마진 구조 투명 | 프라이싱이 블랙박스 |
| 출금 | 온체인 확인 후 즉시 | 수동 심사, 1~5일 소요 |
| 수익 분배 | 마켓 메이커가 마진을 공유 | 모든 수익은 플랫폼이 차지 |
