# 자주 묻는 질문

### 계정 및 연결

| 질문 | 답변 |
|---|---|
| 회원가입이 필요한가요? | 아니요. EVM 지갑을 연결하고 메시지에 서명하면 끝 — 이메일, 비밀번호, KYC 모두 필요 없습니다. |
| 지원하는 지갑은 무엇인가요? | MetaMask, OKX Wallet, Bitget Wallet, Phantom, Binance Wallet, Coinbase Wallet 및 WalletConnect 호환 지갑 모두. |
| OddFi는 어떤 체인에서 운영되나요? | BNB Smart Chain (BSC, chainId = 56). |
| BNB가 필요한가요? | 네 — 가스 비용 지불용입니다. 지갑에 소량의 BNB를 보유하세요. |
| 지갑 계정을 변경하면 어떻게 되나요? | OddFi가 변경을 감지하고 새 주소로 재인증을 요청합니다. |
| 모바일 앱이 있나요? | OddFi는 웹 앱이며 데스크톱과 모바일 모두에 최적화되어 있습니다. 모바일에서는 시스템 브라우저 사용을 권장합니다. |

### 입금 및 출금

| 질문 | 답변 |
|---|---|
| 입금이 도착했는데 잔고가 0입니다? | 입금은 블록 12회 확인이 필요합니다 (약 36초). 5분이 지나도 반영되지 않으면 자산이 BSC 체인의 ODD인지, 올바른 프록시 지갑 주소로 보냈는지 확인하세요. |
| 다른 지갑으로 출금 가능한가요? | 네 — 유효한 EVM 지갑 주소라면 어디로든 가능합니다. |
| 입금 주소가 로그인 지갑 주소와 왜 다른가요? | OddFi는 사용자마다 별도의 프록시 지갑을 입금 주소로 부여합니다 — 어떤 지갑에서 자금을 보내든 플랫폼이 소유권을 인식할 수 있도록 하기 위함입니다. |

### 베팅 및 수익

| 질문 | 답변 |
|---|---|
| 확정 전 배당률이 변동되면 어떻게 되나요? | 0.05를 초과하여 변동하면 시스템이 확인 모달을 띄우고 재확인을 요구합니다. 락되는 배당률은 확정 시점의 배당률입니다. |
| 최소 베팅 금액이 있나요? | 최소 10 ODD. |
| 베팅에 세금이 있나요? | 네 — 베팅 금액 외에 1% 베팅 세금이 ODD로 부과됩니다. 100% 직접 추천인에게 가며, 없으면 플랫폼으로 귀속됩니다. |
| 페이아웃에도 세금이 있나요? | 네 — 5% 페이아웃 세금: 2pp 스테이킹 풀 / 1pp L3 버퍼 / 1pp 플랫폼 / 1pp 직접 추천인. |
| 파레이에서 한 경기 결과가 없고 나머지가 모두 적중하면? | 파레이는 모든 레그가 정산되어야 결과를 산출할 수 있습니다. 한 레그라도 미정산이면 전체 파레이는 Pending 상태를 유지합니다. |

### 포지션 렌딩

| 질문 | 답변 |
|---|---|
| 담보 포지션은 적중했는데 차입 베팅이 미적중하면? | 차입 베팅은 정상 손실 처리 (손실은 담보 원금의 50%로 상한). 담보는 평소대로 페이아웃됩니다. |

### 스테이킹 및 마켓 메이킹

| 질문 | 답변 |
|---|---|
| 스테이킹을 조기 상환하면 무엇을 잃나요? | 원금 100% 반환, 누적된 모든 수익 소실. |
| 스테이킹 수익은 어디에서 오나요? | 페이아웃 세금 2pp + 조기 상환 몰수분. 사용자 스테이크 × 보상 배수 가중치로 분배. |

### 추천 및 토큰

| 질문 | 답변 |
|---|---|
| 추천 관계를 변경할 수 있나요? | 아니요. 최초 바인딩이 온체인에 기록되며 영구적입니다. |
| 추천 보상은 언제 도착하나요? | 실시간 아닙니다. BettingPool에 10 ODD 이상 누적되면 Claim 클릭 — 컨트랙트가 ODD를 USDT로 실시간 스왑하여 지갑으로 전송합니다. |
| 추천 보상을 받으려면 스테이킹이 필요한가요? | 아니요. Clean Token 모델에서 추천인에게는 임계값이 없습니다. |
| ODD 매수/매도에 세금이 있나요? | 아니요. ODD는 Clean Token입니다 — 컨트랙트 레이어에 세금이 없습니다. 모든 세금은 BettingPool 내부에서 베팅과 페이아웃에만 부과됩니다. |
| 1억 공급량은 인플레이션 또는 소각되나요? | 인플레이션 없음. 소각 메커니즘은 월드컵 이후 활성화되며, 구체 사항은 추후 발표됩니다. |
