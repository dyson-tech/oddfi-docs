# 수수료 및 보안

### 플랫폼 전체 수수료 정책

| 작업 | 수수료 | 부담자 |
|---|---|---|
| 입금 (직접 전송) | 가스 비용 | 사용자 |
| 베팅 | **베팅 세금 1% (원금 외 추가 ODD — 100% 직접 추천인 / 없으면 플랫폼)** | 자동 차감 |
| 조기 정산 | 없음 | — |
| 페이아웃 (적중) | **페이아웃 세금 5%** (2pp 스테이킹 / 1pp L3 버퍼 / 1pp 플랫폼 / 1pp 직접 추천인) | 페이아웃에서 차감 |
| ODD 매수 / 매도 | **세금 없음** (컨트랙트 레이어 Clean Token — 매수/매도 세금, 수익세, 쿨다운, 거래당 한도 없음) | — |
| 가스 비용 (모든 온체인 작업) | 온체인 가스 | 사용자 |
| 추천인 Claim (ODD → USDT) | PancakeSwap 0.25% LP 수수료 + 가스 | 추천인 |
| 스왑 입출금 | 표준 DEX 수수료 + 가스 | 사용자 |

### 보안 조치

| 조치 | 설명 |
|---|---|
| 자기 보관 | 모든 사용자 자금은 사용자 지갑이 보유 — 플랫폼이 단독으로 출금 불가 |
| 멀티시그 정산 | 경기 정산은 Gnosis Safe 멀티시그 승인 필요 |
| ReentrancyGuard | StakingPool / BettingPool의 모든 자금 작업이 재진입 공격으로부터 보호됨 |
| Pausable | 3개 핵심 컨트랙트 모두 비상 일시 정지 지원 |
| Claim 슬리피지 보호 | ODD → USDT 실시간 스왑은 기본 2% 슬리피지 상한, 커스터마이즈 가능 (최대 5%) |
| 최소 클레임 임계값 | 10 ODD — 가스 비용이 소액 클레임을 잠식하지 않도록 |
| L3 + L4 버퍼 워터폴 | 극단 페이아웃은 LP 자금 → 플랫폼 금고 → L3 버퍼 → L4 버퍼 풀로 단계적 흡수 — 4단계로 단일 포인트 풀 폭발 방지 |
| 제3자 감사 | 메인넷 출시 전 필수 보안 감사 (CertiK / SlowMist / PeckShield) |
| LP 락 | DEX 유동성 LP 토큰 영구 락업 |
| 가격 조작 방어 | TWAP / 오라클 교차 검증으로 플래시론 공격 방어 |
| 잔고 검증 | 모든 작업에서 프론트엔드 + 컨트랙트 이중 잔고 확인 |

> ODD는 컨트랙트 레이어에 전송 제한이 없는 Clean Token입니다. 가격 안정성은 비즈니스 레이어의 세 가지 메커니즘으로 뒷받침됩니다: 시차 해제 일정, 능동적 전략 비축 방어, 애플리케이션 레이어 세금 순환.

### 리스크 고지

- **스마트 컨트랙트 리스크**: 감사를 거쳤더라도 미발견 취약점이 존재할 수 있습니다. 감당할 수 있는 범위 이상으로 투자하지 마십시오.
- **시장 리스크**: ODD 가격은 시장 요인의 영향을 받습니다. ODD로 표시되는 LP·스테이킹 수익은 가격 변동 리스크를 동반합니다.
- **유동성 리스크**: 락업 기간 내 LP 자금은 조기 상환 시 수익을 잃습니다.
- **경기 리스크**: 엣지 케이스 (경기 취소, 결과 분쟁)에서는 수동 정산 프로세스가 발동되어 페이아웃이 지연될 수 있습니다.
