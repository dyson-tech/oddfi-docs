# 시작하기

### Step 1: 지갑 연결

OddFi는 WalletConnect와 호환되는 주요 EVM 지갑을 모두 지원합니다: MetaMask, OKX Wallet, Bitget Wallet, Phantom, Binance Wallet, Coinbase Wallet 등.

**진행 순서:**
1. 오른쪽 상단의 "Connect Wallet" 클릭
2. 사용할 지갑 선택
3. 연결 요청 승인
4. 인증 메시지 서명
5. 입장 완료

> 첫 서명 시 계정이 자동 등록되며, 재방문 시에는 지갑 주소로 식별됩니다. 온체인 거래는 BSC (chainId = 56)에서 실행되며, 필요 시 플랫폼이 자동으로 네트워크 전환을 안내합니다.
>
> 모바일: 해당 지갑 앱이 설치되어 있으면 곧바로 열려 인증이 진행되며, 그렇지 않으면 다운로드 페이지로 이동합니다.

### Step 2: ODD 확보

ODD는 OddFi에서 유일하게 가격 책정·정산에 사용되는 토큰입니다. 베팅하려면 먼저 ODD가 필요합니다.

ODD 확보 방법:

| 방법 | 설명 |
|---|---|
| PancakeSwap에서 매수 | PancakeSwap의 ODD/USDT 페어 이용 |
| 크로스체인 스왑 | Relay 브릿지를 통해 다른 EVM 체인 자산을 ODD로 스왑 |
| 동일 체인 스왑 | PancakeSwap에서 BNB·USDT 등 BSC 토큰을 ODD로 스왑 |

> ODD는 Clean Token입니다 — 매수·매도·전송 시 **세금이 없습니다**. 추천 보상은 베팅 세금(1%) + 페이아웃 세금(1pp)에서 지급되며, 둘 다 애플리케이션 레이어에서 부과됩니다 ([추천 보상](#8-추천-보상) 참고).

### Step 3: 계정으로 입금

"Wallet" → "Deposit"으로 이동하여 개인 프록시 지갑 주소를 복사하고, 해당 주소로 ODD를 전송하면 블록 12회 확인(약 36초) 후 잔고가 자동 반영됩니다.

자세한 내용은 [입금 및 출금](#4-입금-및-출금) 참고.

### Step 4: 예측 시작

잔고가 반영되면 경기 목록을 둘러보고 원하는 경기와 결과를 선택하여 금액을 입력하고 베팅을 확정하세요.
