# 오즈 메커니즘

### 배당률 생성 방식

플랫폼은 제3자 전문 데이터 소스에서 참고 배당률을 가져와 해당 소스의 원래 마진을 제거하여 실제 확률을 복원한 뒤, OddFi의 10% 마진을 적용해 오프닝 배당률을 산출합니다.

```
페이아웃 배당률 = 1 / (실제 확률 × Overround 계수)
```

표준 Overround: 110%.

### 배당률 읽기

| 배당률 | 함의 확률 | 의미 |
|---|---|---|
| 1.5 | 66.70% | 강한 우세 — 낮은 수익률 |
| 2.0 | 50.00% | 50/50 — 베팅 금액의 2배 |
| 3.0 | 33.30% | 약세 — 베팅 금액의 3배 |
| 5.0 | 20.00% | 큰 약세 — 베팅 금액의 5배 |

### 동적 조정

각 베팅 후 시스템은 양쪽 사이드의 베팅 불균형을 감지하여 동적으로 조정합니다:

- **무거운 쪽**: 배당률이 축소됨 (플랫폼 리스크 감소)
- **가벼운 쪽**: 배당률이 상향 조정됨 (반대편 베팅을 유도, 익스포저 균형)

배당률은 경기 시작 1시간 전에 락되며 이후 변동되지 않습니다. 0.05 초과 변동은 실시간으로 프론트엔드에 푸시됩니다.

### 배당률 변동 재확인

금액 입력과 확정 사이에 배당률이 0.05를 초과하여 변동하면 시스템이 최신 배당률을 표시하는 모달을 띄우며, 사용자는 반드시 재확인해야 합니다. 락되는 배당률은 확정 시점의 배당률입니다.
