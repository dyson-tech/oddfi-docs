# 추천 보상

지갑을 연결하면 자동으로 고유한 추천 링크가 생성됩니다. 추천 관계는 온체인에 영구 바인딩되며 한 번 바인딩되면 변경할 수 없습니다.

### 보상 원천

| 보상 종류 | 규칙 |
|---|---|
| 베팅 세금 분배 | 피추천인이 베팅할 때마다, 베팅 원금의 **1% ODD**를 추천인이 획득 |
| 페이아웃 세금 분배 | 피추천인이 적중하여 페이아웃을 받을 때마다, 페이아웃의 **1% ODD**를 추천인이 획득 (5pp 페이아웃 세금 중 1pp) |
| 팀 등급 보너스 | 아래 S1~S5 사다리 참고 |

> 보상 수령에 스테이킹 임계값이 없습니다. 추천인이 없는 사용자의 경우, 원래 추천인에게 갈 1% 베팅 세금 + 1pp 페이아웃 세금 분배분이 플랫폼 금고로 귀속됩니다.

### 클레임 메커니즘 (중요)

추천 보상은 실시간으로 입금되지 않습니다 — BettingPool 컨트랙트 내부에 누적되며 사용자가 능동적으로 클레임합니다:

```
피추천인 베팅/적중 → BettingPool에 ODD가 본인 Claim 잔고로 누적
  ↓
클레임 가능 ODD 잔고 확인
  ↓
Claim 클릭 → 컨트랙트가 PancakeSwap을 통해 ODD → USDT 실시간 스왑
  ↓
USDT가 본인 지갑으로 직접 입금
```

| 항목 | 설명 |
|---|---|
| 최소 클레임 임계값 | 10 ODD (가스 비용이 소액 클레임을 잠식하지 않도록) |
| 스왑 경로 | PancakeSwap V2 Router (ODD → USDT) |
| 슬리피지 보호 | 기본 2%, 커스터마이즈 가능 (최대 5%) |
| 가스 비용 | 추천인 부담 |
| 실패 처리 | 스왑 실패 시 전체 클레임 롤백; ODD 잔고는 보존 |

> 설계 의도: USDT 정산으로 추천인이 ODD 가격 변동에 노출되지 않도록 하며, 단일 Claim 이벤트로 여러 소액 전송 대비 가스를 절감합니다.

### 팀 등급 보너스

| 등급 | 팀 누적 베팅 | 팀 보너스 |
|---|---|---|
| — | < $10,000 | 기본 분배만 (1% 베팅 세금 + 1pp 페이아웃 세금), 보너스 없음 |
| S1 | ≥ $10,000 | +0.04 |
| S2 | ≥ $50,000 | +0.08 |
| S3 | ≥ $100,000 | +0.12 |
| S4 | ≥ $500,000 | +0.16 |
| S5 | ≥ $1,000,000 | +0.20 |

> 등급 차액 모델: 상위 추천인은 차액만 획득하며 하위의 전체 몫을 가져가지 않습니다. 보너스는 생태계 인센티브 풀에서 지급되며 메인 Claim 경로와 분리되어 있습니다.
>
> 팀 베팅은 경기가 정산된 후에만 팀 누적 거래량에 반영되어 보상을 트리거합니다.

### 첫 입금 보상

| 첫 입금 금액 | 피추천인 수령 | 추천인 수령 |
|---|---|---|
| ≥ $50 | 10 ODD | 5 ODD |
| ≥ $200 | 50 ODD | 25 ODD |
| ≥ $500 | 150 ODD | 75 ODD |
| ≥ $1,000 | 350 ODD | 175 ODD |

보상은 30일 락업 후 클레임 가능합니다.
