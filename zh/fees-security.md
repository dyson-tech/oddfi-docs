# 费用与安全

### 全平台手续费总表

| 操作 | 手续费 | 支付方 |
|---|---|---|
| 充值（直接转账） | Gas fee | 用户 |
| 下注 | **下注税 1%（额外付，全部归直推人 / 无直推归平台）** | 自动扣除 |
| 提前结算 | 无 | — |
| 派奖（中奖） | **派奖税 5%**（2pp 质押池 / 1pp L3 缓冲 / 1pp 平台 / 1pp 直推人） | 从派奖中扣除 |
| 买入 / 卖出 ODD | **零税**（合约层 Clean Token，无买卖税、无利润税、无冷却、无单笔上限） | — |
| Gas 费（所有链上操作） | 链上 Gas fee | 用户 |
| 推荐人 Claim（ODD → USDT） | PancakeSwap 0.25% LP 手续费 + Gas | 推荐人 |
| 充值 / 提现（兑换路径） | DEX 标准费率 + Gas | 用户 |

### 安全措施

| 措施 | 说明 |
|---|---|
| 资金托管 | 所有用户资金由用户钱包自托管，平台无法单方面提取 |
| 多签结算 | 赛事结算需要 Gnosis Safe 多签钱包审批 |
| ReentrancyGuard | StakingPool / BettingPool 所有资金操作防重入 |
| Pausable | 三个核心合约均支持紧急暂停 |
| Claim 滑点保护 | ODD→USDT 现场 swap 默认 2%，用户可自定义（上限 5%） |
| 最小 Claim 门槛 | 10 ODD，防止 gas 吞噬小额收益 |
| L3 税缓冲瀑布 | 极端赔付按 LP 资金 → 平台金库 → L3 缓冲三层兜底，避免单点爆池 |
| 第三方审计 | 主网部署前强制完成安全审计（CertiK / SlowMist / PeckShield） |
| LP 锁定 | DEX 流动性池 LP Token 永久锁仓 |
| 价格操纵防护 | TWAP / 预言机交叉验证，防范闪电贷攻击 |
| 余额校验 | 所有操作前端 + 合约双重余额校验 |

> v2.4 的「交易冷却 1 分钟 / 单笔卖出上限 10% / 卖出利润税 25%」已全部废弃 — ODD 升级为 Clean Token，转账无任何限制。价格稳定改由释放节奏错峰、战略储备主动护盘、应用层税收回流三条业务机制支撑。

### 风险提示

- **智能合约风险**：虽经审计，合约仍可能存在未发现漏洞，请勿投入超过承受范围的资金
- **市场风险**：ODD 价格受市场影响，做市和质押收益以 ODD 计价时存在价格波动风险
- **流动性风险**：做市用户资金处于锁定期间无法提前无损提取
- **赛事风险**：极端情况下（赛事取消、争议结果）可能触发人工结算流程，结算时间延后
