# 添加流动性（做市）

向 Betting Pool 注入 ODD，成为平台的对手方流动性提供者。用户预测命中由 Betting Pool 支付，未命中归入 Betting Pool，做市用户按份额分享平台整体盈利。

### 收益构成

| 项目 | 说明 |
|---|---|
| LP 收益 | 平台整体 Margin × 80%，按份额分配 |
| 平台收益 | 平台整体 Margin × 20% |
| 资金安全垫 | 派奖税 1pp（L3 税缓冲）持续注入 BettingPool 内部储备，提升偿付能力 |

> ODD 升级 Clean Token 后，Betting Pool 不再由「卖出利润税 4pp」补充。资金安全由初始 1,500 万 ODD 锁仓本金 + L3 税缓冲共同保障。

收益按「你的存入金额 / 池子总金额」比例分配。

### 锁定期与收益乘数

| 锁定期 | 收益乘数 |
|---|---|
| 7 天 | 0.5x |
| 14 天 | 1.0x |
| 28 天 | 1.8x |
| 60 天 | 2.5x |
| 90 天 | 3.5x |

### 赎回规则

- **到期赎回**：本金 100% 返还，收益正常领取
- **提前赎回**：本金 100% 返还，**收益 100% 罚没**

### 风险提示

做市用户承担平台整体亏损风险。若某段时期用户预测总命中率偏高，Betting Pool 净流出，做市用户可能面临阶段性收益为负。平台通过动态倍率和信号灯系统控制单盘敞口，并通过 L3 税缓冲提供额外兜底。
