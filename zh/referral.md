# 邀请奖励

连接钱包后，每个用户自动获得唯一邀请链接。邀请关系链上永久绑定，一旦绑定不可更改。

### 收益来源

| 收益类型 | 规则 |
|---|---|
| 下注税分成 | 被邀请人每次下注，你获得下注本金的 **1% ODD** |
| 派奖税分成 | 被邀请人每次中奖派奖，你获得派奖金额的 **1% ODD**（派奖税 5pp 中的 1pp） |
| 团队级差加成 | 见下方 S1–S5 阶梯 |

> 推荐人无需质押门槛即可获得收益。无邀请人的用户，1% 下注税 + 1pp 派奖税分成归平台金库。

### Claim 机制（重要）

推荐收益不实时到账，在 BettingPool 合约内累积，由你主动领取：

```
被推荐人下注/派奖 → BettingPool 累积 ODD 到你的 Claim 账户
  ↓
你查看可提取 ODD 余额
  ↓
点击 Claim → 合约通过 PancakeSwap 现场 swap ODD → USDT
  ↓
USDT 直接打到你的钱包
```

| 项目 | 说明 |
|---|---|
| 最小 Claim 门槛 | 10 ODD（防止 gas 吞噬小额收益） |
| Swap 路由 | PancakeSwap V2 Router（ODD → USDT） |
| 滑点保护 | 默认 2%，可自定义（上限 5%） |
| Gas | 推荐人自付 |
| 失败处理 | Swap 失败整笔 revert，ODD 余额保留 |

> 设计逻辑：用 USDT 到账避免推荐人承担 ODD 价格波动风险，单次 Claim 也比每笔小额转账更省 gas。

### 团队级差奖励

| 等级 | 团队累计预测 | 团队返佣加成 |
|---|---|---|
| — | < $10,000 | 仅基础分成（下注税 1% + 派奖税 1pp），无加成 |
| S1 | ≥ $10,000 | +0.04 |
| S2 | ≥ $50,000 | +0.08 |
| S3 | ≥ $100,000 | +0.12 |
| S4 | ≥ $500,000 | +0.16 |
| S5 | ≥ $1,000,000 | +0.20 |

> 采用级差制：上级只拿差额，不重复抽取下级全部收益。加成部分从生态激励池发放，不影响 Claim 主路径。

### 首充奖励

| 首充金额 | 被邀请人获得 | 邀请人获得 |
|---|---|---|
| ≥ $50 | 10 ODD | 5 ODD |
| ≥ $200 | 50 ODD | 25 ODD |
| ≥ $500 | 150 ODD | 75 ODD |
| ≥ $1,000 | 350 ODD | 175 ODD |

奖励锁定 30 天后可提取。
