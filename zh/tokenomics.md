### 税收机制（应用层两点税制）

> 所有税收均在 **BettingPool 合约** 内扣收，ODD 代币合约本身无税收逻辑。用户持有 / 转账 / 做市 / 跨链全程零摩擦。

#### 下注税：1%

用户每次下注时，在本金之外额外支付 1% ODD：

| 去向 | 比例 | 说明 |
|---|---|---|
| 直推人（Claim 账户） | 100% | 累积到直推人账户，由推荐人主动 Claim |
| 无直推人 | — | 100% 归平台金库 |

**示例：** 下注 1,000 ODD → 钱包实扣 1,010 ODD（1,000 本金 + 10 税）。

#### 派奖税：5%（仅对中奖派奖征收）

| 去向 | 比例（pp） | 说明 |
|---|---|---|
| 质押池分红 | 2pp | 分配给所有活跃质押用户（rewardPerShare 模式） |
| L3 税缓冲 | 1pp | 进入 BettingPool 内部储备，兜底极端赔付 |
| 平台金库 | 1pp | 转入多签地址 |
| 直推人（Claim 账户） | 1pp | 累积到直推人账户，由推荐人主动 Claim |
| **合计** | **5pp** | — |

**示例：** 中奖派奖 10,000 ODD → 实到账 9,500 ODD（200 质押池 / 100 L3 / 100 平台 / 100 直推）。

### 增长飞轮

```
更多用户下注
  ↓
BettingPool 收取 下注税 1% + 派奖税 5%
  ↓
  ├─ 下注税 1% ──→ 直推人 Claim（ODD → USDT）→ 激励推广
  └─ 派奖税 5%：
      ├─ 2pp → 质押池分红 ──→ APY 提升 ──→ 更多用户锁仓 ODD
      ├─ 1pp → L3 税缓冲 ──→ BettingPool 偿付能力增强
      ├─ 1pp → 平台金库 ──→ 运营 / 回购 / 生态
      └─ 1pp → 直推人 Claim ──→ 激励推广
  ↓
质押锁仓 + VIP 下注需求 → 自然买盘 → 价格上涨
  ↓
流水放大 → 税收绝对额放大 → 质押 APY 再提升（循环）
```
